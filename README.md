# Lab Evaluation

## Overview

This repository contains the implementation and performance evaluation of parallel vector addition using OpenMP.

The experiment analyzes execution time, speedup, and efficiency for different vector sizes and thread configurations.

## Experiment

### Parallel Vector Addition using OpenMP

- Vector size: 10,000,000
- Programming model: OpenMP
- Threads used: 1, 2, 4, and 8
- Operation: Vector addition
- Performance metric: Execution time
